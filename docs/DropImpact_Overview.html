왜 필요한가

한 번의 낙하 시험으로는 "그 자세에서 안 깨졌다"만 알 수 있습니다.

지금의 한계

자세를 못 고른다

실제 낙하는 무작위 자세로 떨어집니다. 6면 낙하만 검증하면 모서리·꼭짓점처럼 응력이 집중되는 자세를 놓칩니다.

위치를 못 고른다

부분 충격은 어디를 맞느냐로 결과가 뒤집힙니다. 대표점 몇 개로는 가장 취약한 지점을 특정할 수 없습니다.

사람이 못 감당한다

자세 500가지를 손으로 만들면 모델링·제출·수집에만 수 주가 걸립니다. 실수도 그만큼 늘어납니다.

얻는 것

전수 탐색 — 놓치는 자세가 없다

구면을 균등하게 덮는 자세 집합을 자동 생성합니다. 면·모서리·꼭짓점 26방향을 시드로 먼저 배치하고 그 사이를 채우는 방식도 지원해, 표준 시험 자세를 반드시 포함시킬 수 있습니다.

단계적 확장 — 앞선 결과를 버리지 않는다

120개를 먼저 돌려 경향을 보고, 이어서 500·1000개로 넓힐 수 있습니다. 이전 단계 위치는 그대로 두고 빈틈만 채우므로 재계산이 없습니다.

정량 판정 — 감이 아니라 숫자

파트별 최대 응력·소성변형률·가속도와 안전계수(항복응력÷피크응력)를 전 케이스에 대해 산출하고, 항복 예상 파트를 자동 경고합니다.

재현성 — 언제 돌려도 같은 조건

같은 설정이면 같은 자세 집합이 나옵니다. 설계 변경 전후를 동일 조건에서 직접 비교할 수 있습니다.

의뢰자가 준비할 것은 두 가지뿐입니다 낙하·충격 조건이 전혀 들어있지 않은 순수 해석 모델과, 조건을 적어 넣은 scenario.json. 바닥판, 초기 속도, 접촉, 출력 카드는 모두 자동으로 만들어집니다. (→ 6·7페이지)

전각도 낙하 DROP

제품을 모든 자세로 떨어뜨려 가장 위험한 방향을 찾습니다.

기본 개념

제품 자세를 Roll·Pitch·Yaw 로 바꿔가며 같은 높이에서 떨어뜨립니다. 자세 하나가 해석 케이스(DOE) 하나입니다. 구(球) 표면 위의 한 점이 낙하 방향 하나에 대응하므로, 구면을 얼마나 촘촘히 덮느냐가 곧 검증 밀도입니다.

모델을 회전시키지 않습니다 제품은 원본 자세를 유지한 채, 바닥판을 기울여 같은 효과를 냅니다. 덕분에 모든 케이스에서 제품 좌표계가 동일해 후처리 비교가 쉽습니다.

자세를 만드는 5가지 방법

방식케이스 수쓰임새
cuboid_geometry최대 26
면6+모서리12+꼭짓점8		표준 낙하 시험 대응. 가장 기본이며 기본값입니다.
fibonacci_lattice임의 (26~41,253)전각도 낙하의 주력. 구면 균등 분포를 원하는 개수만큼 생성합니다.
pitching_sweep기본 19Pitch 만 −90°~90° 훑기. 특정 축 경향 분석용.
rolling_sweep기본 36Roll 만 −180°~170° 훑기.
case_txt_file파일에 따름기존 각도 목록 파일 재사용. 특정 인덱스만 골라 쓸 수도 있습니다.

자세가 정말 고르게 퍼지는가

낙하 자세는 실제 충격 방향이 고르게 퍼져야 의미가 있습니다. 방향들 사이 각거리를 재보면 구성에 따라 결과가 크게 다릅니다. (N=100 기준 실측)

구성최소 간격중앙최대최대÷최소중복 방향
구 방식 (위도·경도 균등)0.41°5.09°26.70°65.6배2쌍
기본값 (실제 낙하 방향 균등)17.78°19.39°19.73°1.1배0
표준 26자세 + 채움10.80°16.91°21.57°2.0배0
기본값이 이미 균등합니다 간격이 1.1배 안에서 고르고 중복 방향이 없습니다. 구 방식은 간격이 66배까지 벌어지고 같은 방향이 중복으로 뽑히는 문제가 있었습니다 (첨부한 예제 리포트가 구 방식으로 돌린 것이라 20개 중 1쌍이 중복입니다).

고급 옵션

principal_directions: "cuboid26"

면 6 · 모서리 12 · 꼭짓점 8 = 표준 26자세를 반드시 포함시키고, 나머지를 균등 분포에서 가져와 채웁니다. 100개면 26 + 74 입니다. 표준 낙하 시험과 대조해야 할 때 씁니다.

previous_stages

단계적 확장. [120, 500] + num_points: 1000 이면 이미 돌린 500개를 재현해 제외하고 신규 500개만 내보냅니다.

sampling_space: "latlon"

구 방식으로 되돌립니다. 과거에 돌린 결과와 각도를 맞춰야 할 때만 쓰십시오. 신규 프로젝트에는 권장하지 않습니다.

단계적 확장이 왜 유용한가

작게 시작해 필요하면 넓히는 방식이 가능합니다. 단계 목록만 선언하면 어느 경로로 확장하든 누적 위치 집합이 항상 동일합니다.

# 1단계 — 경향 파악
num_points: 120

# 2단계 — 빈틈 채우기 (신규 380개)
num_points: 500
previous_stages: [120]

# 3단계 — 정밀화 (신규 500개)
num_points: 1000
previous_stages: [120, 500]

대가는 균일도가 약간 낮아지는 것입니다. 실측값입니다.

구성최소 간격중앙값
누적 1000 (120→500→1000)3.15°4.73°
정규 1000 (한 번에)5.60°6.10°
정규 대비 최악 간격 56% 서로 다른 격자를 겹치는 데서 오는 불가피한 손실입니다. 다만 중복·뭉침은 0개이고 중앙값은 거의 유지됩니다. 최고 균일도가 필요하면 단계 없이 목표 개수를 한 번에 돌리십시오.
단계를 빠뜨리면 안 됩니다 실제로 120 → 500 을 돌려놓고 previous_stages: [500] 이라고만 적으면 재현이 어긋나 1000개 중 4개가 1° 이내로 겹칩니다. 로그의 "재현 누적 N개" 가 실제 돌린 개수와 같은지 확인하십시오.

전위치 부분충격 IMPACT

제품 표면 곳곳을 때려 가장 취약한 지점을 찾습니다.

기본 개념

제품은 고정하고 충격추(impactor)를 떨어뜨립니다. 때리는 (x, y) 위치 하나가 케이스 하나입니다. 낙하가 "어느 자세로 떨어지나"를 훑는다면, 부분충격은 "어디를 맞으면 위험한가"를 훑습니다.

낙하와의 핵심 차이

전각도 낙하전위치 부분충격
훑는 대상자세 (Roll/Pitch/Yaw)위치 (x, y)
설정 키angle_sourceposition_source
움직이는 것제품이 떨어짐충격추가 떨어짐

위치를 만드는 3가지 방법

방식설명
grid_nxm
기본값		nx × ny 균등 격자. 범위(bbox)를 생략하면 모델 전체에서 자동 계산합니다. 5×5 = 25 케이스.
grid_spacing간격(mm)으로 지정. 제품 크기가 달라도 동일한 밀도를 유지합니다.
manual좌표를 직접 나열. 커넥터·버튼 등 특정 지점만 집중 검증할 때.
충격추 형상 구(Sphere)가 기본이며, 원통(cylinder)은 다단 구조(앞/중간/뒤 지름·높이·재질을 따로)까지 정의할 수 있어 실제 시험 지그를 모사할 수 있습니다.

설정 예시 — 5×5 격자 25지점

"position_source": {
  "source_type": "grid_nxm",
  "grid_nxm": { "nx": 5, "ny": 5, "bbox": [-40, -40, 40, 40] }
},
"simulation_params": {
  "impact": {
    "type": "Sphere",      // 충격추 형상
    "dimension": 8,          // 지름 8 mm
    "height": 500,          // 낙하 높이 500 mm → 속도 자동 계산
    "mesh_size": 1,          // 충격추 메시 크기
    "density": 7.85e-9,     // 강 (ton/mm³)
    "youngs_modulus": 201000, // MPa
    "tFinal": 0.001, "dt": 1e-6
  },
  "wall": { "density": 1e-9, "youngs_modulus": 10000 }  // 받침판
}
단위계 주의 — 가장 흔한 사고 impact 하위 값의 기본값은 SI(m) 기준입니다(dimension 0.008, height 0.5). ton-mm-s 모델에서 생략하면 1000배 작은 충격추가 만들어집니다. 반드시 명시하십시오.
속도는 높이로만 정합니다 체인 IMPACT 경로에서 초기 속도는 0으로 고정되어 있고, 충격 속도는 height 에서 자동 계산됩니다. 속도를 직접 지정할 수는 없습니다.

전위치 부분충격 — 무엇을 볼 수 있나

위치 × 부품 조합 전체를 훑어 취약 지점을 짚어냅니다.

핵심 데이터 구조

통합 리포트의 뼈대는 (위치 × 부품) 격자입니다. 조합마다 4개 지표가 기록됩니다.

peak_g
최대 충격 가속도
peak_stress
최대 응력
peak_strain
최대 변형률
peak_disp
최대 변위
규모 예시 25지점 × 25부품이면 625개 조합이 하나의 표로 정리됩니다. "어느 위치를 때렸을 때 어느 부품이 가장 위험한가"를 정렬 한 번으로 알 수 있습니다.

의뢰 시 준비물

낙하·충격 조건이 없는 순수 모델 한 벌 + scenario.json 한 장.

모델에 반드시 있어야 할 것

카드요건
*NODE필수 없으면 즉시 중단됩니다.
*ELEMENT_*필수 SOLID / SHELL / BEAM / MASS 중 최소 1종.
*PART필수 제목줄 + 데이터줄 2줄 쌍 구조. 제목이 비어도 줄 자체는 있어야 합니다.
*SECTION_*필수 PART 의 SECID 에 대응.
*MAT_*필수 PART 의 MID 에 대응. 밀도·탄성계수가 있어야 합니다.
파트 간 접촉필수 제품 내부 부품끼리의 접촉은 모델에 있어야 합니다. 자동 생성되는 것은 제품↔바닥판 접촉뿐입니다.
고정폭 컬럼을 반드시 지키십시오 절점·재료 카드는 고정폭으로만 읽습니다. 콤마나 가변 공백으로 쓴 절점은 에러 없이 좌표가 0이 되어 원점에 뭉칩니다. 재료 카드도 한 칸 밀리면 물성을 못 읽은 것처럼 보입니다.
단위계는 ton-mm-s 로 통일 길이 mm · 질량 tonne · 밀도 ton/mm³ · 탄성계수 MPa · 시간 s. 단위 변환을 하지 않고 그대로 씁니다.

넣지 말아야 할 것

낙하·충격 조건은 빼 주십시오
  • *INITIAL_VELOCITY — 자동 생성분과 중복 적용됩니다
  • 제품 파트의 *BOUNDARY_SPC — 자유낙하가 막힙니다
  • 바닥판·충격추 모델 — 자동 생성됩니다

자동으로 만들어 드리는 것

자동바닥판 파트·절점·요소 (크기·메시 자동 산정)
자동바닥판 전용 단면·재료·하면 구속
자동낙하 높이 → 초기 속도·각속도
자동제품 ↔ 바닥판 접촉
자동해석 종료 시간, d3plot 등 출력 카드
자동누적 해석용 응력 이월 카드

그대로 보존되는 것

보존*CONTROL_* 정밀도 설정 — 의뢰 모델 값이 우선
보존*DATABASE_EXTENT_BINARY (STRFLG 등)
보존기존 Tied 접촉, 감쇠, 세트, 타이틀
보존*KEYWORD 옵션(I10=Y 등), *PARAMETER
응력 텐서를 보시려면 *DATABASE_EXTENT_BINARY 의 STRFLG 를 모델에 직접 넣어 주십시오. 이 카드는 자동 생성하지 않으며, 넣으신 값은 전 과정에서 그대로 유지됩니다.
