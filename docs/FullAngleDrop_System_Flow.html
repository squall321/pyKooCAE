◎① 방향을 어떻게 고르나

구(球) 위에 낙하 방향을 점으로 뿌린다. 각 점 = 하나의 (roll, pitch, yaw) 자세 = 하나의 DOE.

Fibonacci 격자 — 구면 균등
Progressive 순서 — 듬성→촘촘

🌐 전수 1천 각도

  • Fibonacci 격자 num_points≈1000을 전부 해석.
  • 완전한 커버리지, 그러나 비용·시간 최대.
  • 중간에 멈추면 한쪽만 돌아 편향.

🎯 적응 샘플링

  • 같은 1천 점을 progressive 순서로 정렬.
  • 앞부분만 돌려도 전구면 균등(의미있는 조기 결론).
  • 위험영역 발견 시 그 근처를 우선 촘촘히.

↻적응 재배치 루프 모델 C · 고정 격자

새 점을 만들지 않는다. 이미 던져진 잡 중 대기 중인 것의 실행 순서만 위험도로 바꾼다.

P1
Harvest + 리스크

완료 result.json 수집 → 파트별 z-score(상대) + yield 절대비. 평균보다 유의미하게 높으면 핫.

P2
미실행 점 우선순위

대기 방향마다 priority = Σ 핫(risk)×커널(각거리). 핫 근처일수록 높음. 탐색 30% 혼합.

P3
scontrol 재배치

top(핫 근처 우선) / hold(원거리 후순위). simulation_index로 run↔DOE↔job 매핑.

⚙② 전처리 · KooMeshModifier

방향 1개당 해석용 .k 1개를 만든다. DropAttitude 모드가 모델을 회전시키고 바닥·접촉·조건을 붙인다.

  1. 모델 중심 정규화바운딩박스 중심을 원점으로. 회전 기준점 확보.
  2. 오일러 회전 (roll·pitch·yaw)RotMat = Rz·Ry·Rx 로 제품을 목표 자세로. 바닥은 수평 유지.
    euler_to_vecZYX
  3. 낙하 면 생성Plane · PlaneGraded(중심 미세+외곽 거침) · Roughness · RigidWall 택1.
    PlaneGradedRigidWall
  4. 접촉 생성SINGLE_SURFACE(SOFT=2). robust_contact는 Tied 면 제외 segment로 교체, DEPTH=3.
    SS · SOFT=2robust_contact
  5. CONTROL 카드TIMESTEP TSSFAC=0.7 · HOURGLASS IHQ=5/QH=0.1 · DAMPING coef≥0.01 · TERMINATION.
    TSSFACIHQ=5
  6. 초기 속도사용자 속도 + 낙하높이 v=√(2gh). RotMat로 자세에 맞게 회전.
  7. 경계 조건전체 SPC 고정 또는 BOUNDARY_NON_REFLECTING(응력파 흡수)+꼭짓점 3점 최소 SPC.
    NON_REFLECTING
  8. 출력 요청D3PLOT·NODOUT·ELOUT + NCFORC·INTFOR(접촉력/penalty 분석).

부가 모드 · RIGIDIFY_SMALL_DT 최소 dt 요소 강체화   FastDOE 다각도 캐싱 가속   PART_VALIDATION_SPLIT 파트 독립 검증

▦③ 후처리 · 3종 리포트

핵심 직관 · deep=개별 1건, sphere=각도 종합, impact=위치 종합.

🔬 deep report
개별 · per-job
입력 d3plot+glstat→출력 result.json+html
파트별 von Mises 최대응력·발생시각·변형률·변위·가속도. MAT 카드의 stress_limit로 안전계수·warn/crit 판정. 성공 후 d3plot 삭제(방법1) → 디스크 절약.
🌐 sphere report
각도 종합 · DROP
입력 각 방향 result.json→출력 구면 히트맵
전 방향 deep 결과를 구면(낙하 각도)에 매핑(Mollweide). 파트별 최대응력을 색으로 → 최악 낙하 방향·핫스팟 한눈에. d3plot 아닌 JSON만 읽어 방법1과 호환. 정상종료 잡만 집계.
🎯 impact report
위치 종합 · IMPACT
입력 각 위치 result.json→출력 면 위 히트맵
충격자(구/원기둥)가 면의 여러 위치를 때린 결과를 (면,위치,파트) 격자로 종합. 면 위에 위치별 응력·G·변형률 분포 → 최악 충격 위치. sphere는 방향, impact는 위치 분포라는 점이 차이.

⚡왜 적응 샘플링인가

1천 잡을 전부 끝까지 기다리지 않아도, 위험한 방향을 먼저·촘촘히 찾아낸다.

  • ① 전체를 듬성듬성(progressive) 돌려 전구면 1차 스캔.
  • ② deep 결과에서 파트별 응력이 평균 대비 유의미하게 높은 핫 방향 식별.
  • ③ 그 근처 대기 잡을 우선 실행하도록 큐 재배치 → 위험영역 고해상.
  • ④ 예산이 끊겨도 가장 중요한 방향은 이미 확보.
Fibonacci 황금각
φ = π(3−√5) ≈ 137.508°
yᵢ=1−2i/(N−1), θᵢ=φ·i → 구면 균등 분포.
오일러 ↔ 벡터
roll=asin(y)−90°
pitch=−atan2(z,x)
방향벡터와 (roll,pitch,yaw) 자세를 가역 변환.
리스크 (핫 판정)
risk=maxₚ[ max(0,z) + max(0,a−1) ]
z=상대(평균대비), a=σ/yield 절대비. 둘 다 본다.
우선순위 (재배치)
priority(u)=Σₕ risk(h)·e^−(d/r)²
대기 방향 u가 핫 h에 가까울수록(각거리 d↓) 우선.
