# 계획 — `*ELEMENT_SOLID (ten nodes format)` 절삭 절점줄

## 증상 (2026-10-22, 배포본 SIF v119 로 재현)

`(ten nodes format)` 선언 블록에서 Card 2(N1~N10) 줄이 64자(n9·n10 생략)이면 이렇게 된다.

| 요소 | 입력 | KMM 출력 |
|---|---|---|
| 1 | n1~n8 | n1~n8 + **n9=2, n10=1** (다음 요소의 EID·PID 를 절점으로 흡수) |
| 2 | n1~n8 | **소실** (절점줄이 "헤더 형식 이상"으로 버려짐) |
| 3 (마지막) | n1~n8 | 정상 |

- 개수 검사는 "입력 2 = 등록 2 (소실 0)" 라고 찍는다. 입력을 파싱 결과로 세기 때문에 소실을 보지 못한다.
- 결과적으로 요소가 하나 걸러 사라지고, 살아남은 요소는 접속이 오염된다. 무증상이다.
- 접수된 진단은 "64자 줄을 조용히 버린다" 였지만 실제 메커니즘은 위와 같다. 고칠 곳(64자 줄을 완결 카드로 볼 것)은 맞다.

## 근거 — LS-DYNA R16 Vol I 원문

- `*ELEMENT_SOLID` 의 Card 2 는 N1~N10 10필드 카드 한 장이다. 4절점 사면체는 "N1, N2, N3, N4, N4, N4, N4, N4, 0, 0", 6절점 오면체는 "…, N6, N6, 0, 0" 으로 쓴다.
- GENERAL CARD FORMAT 에는 두 규칙이 있다.
  - 카드는 80자 줄 하나다. 80열을 넘는 글자는 무시한다.
  - Default 는 "0 을 주거나, 칸을 비우거나, 카드가 없을 때" 쓰는 값이다.
- 따라서 표준(I8) 에서 64자 줄은 n9·n10 이 빈 정상 카드다.
- I10 은 "8칸 필드를 10칸으로 늘린다" 고만 적혀 있다. 줄을 나눈다는 말은 없다.

## 원인

`ElementSolid._parse_ten_nodes_block` 의 "랩 우선" 상태머신(9118818) 때문이다. 이 상태머신은 노드가 10개 찰 때까지 다음 줄을 전부 노드로 흡수한다.
- 7월 서버 덱(B7·M1, I10)의 8+2 줄 넘김과 2개씩 넘김 TET10 을 받으려고 넣었다. 그때 "절삭 덱은 미지원(비크래시)" 으로 알고 넘겼다.
- 35c6f79(A27) 는 선언이 없는 블록만 expect=8 로 고쳤다. 선언 블록(expect=10)에 64자 줄이 오는 경우가 남았다.

## 수정 — 지금 요소를 잃는 경우만 바로잡는다

- 규칙: 노드를 8개 받은 요소에 2필드 줄이 오면, 그다음 실데이터 줄을 미리 본다.
  - 그 줄이 **옛 동작이 헤더로 못 읽어 버릴 줄**(`_split_header` None)이고 전부 정수(노드줄)면, 2필드 줄은 이어진 n9·n10 이 아니라 **다음 요소의 헤더**다.
  - (처음엔 '다음 줄이 2필드가 아니면' 이었으나 적대 리뷰가 반례를 찾아 바꿨다. 폭이 섞인 블록·잡문·쉼표 카드에서 옛 판이 맞던 결과를 깼다 — 컨텍스트 노트)
  - 그러면 지금 요소를 n9=n10=0 으로 마감한다.
- 이 경우 지금 코드는 2필드 줄을 n9·n10 으로 먹은 뒤, 다음 노드줄을 "헤더 형식 이상"으로 버린다. 즉 **지금 요소를 잃는 경우에만 동작이 바뀐다.**
  - 8+2·4+4+2·2개씩·1개씩 넘김은 바뀌지 않는다. 그 경우 2필드 줄 다음에는 다음 헤더(2필드)나 블록 끝이 온다.
  - 남는 한계는 '절삭 카드와 2개씩 넘긴 카드가 한 블록에 섞인 것' 이다. 모양만으론 경계를 못 가린다 → 🔴 로 알린다.
  - 선언 없는 블록(expect=8)은 8에서 이미 마감하므로 바뀌지 않는다.
- 남는 경우: 그래도 버리는 줄이 있으면 🔴 요약을 낸다. 몇 줄을 요소로 못 읽었는지 알려 무증상을 막는다.
- 최종 판정(적대 리뷰 3회 반영)은 세 조건을 모두 볼 때만 바꾼다. 옛 판이 줄을 버리는 경우에만 바뀐다는 성질은 구조상 참이다.
  ① 바로 다음 줄이 헤더 모양이 아니다(_split_header None)
  ② 다음 헤더 앞까지의 줄이 전부 정수다
  ③ 그 필드 합이 정확히 8(헤더·끝 경계) 또는 10 이다
- 안내: 선언 블록에서 8절점으로 마감한 카드 수를 블록마다 한 줄로 늘 찍는다.
