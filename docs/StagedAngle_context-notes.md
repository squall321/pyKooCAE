# Staged 각도 샘플링 — 결정 기록

## 왜 "중첩 시퀀스" 가 아니라 "이전 단계 선언 + 최근접 제거" 인가

처음엔 후보풀을 N 과 무관하게 고정해 `120 ⊂ 500 ⊂ 1000` 이 정확히 성립하는 **중첩
시퀀스**를 제안했다. 이론적으로 더 깔끔하지만, **이미 돌린 결과를 버려야 한다.**

사용자 지적이 결정적이었다 — 각 단계 생성이 이미 결정론적이므로, 이전 단계 목록만
선언하면 이전 위치를 재현할 수 있고 따라서 누적 결과도 항상 같다. 중첩을 만들 필요 없이
목표(항상 같은 위치 셋 + 기존 결과 재사용)가 둘 다 달성된다. 실측으로 확인 후 채택.

## 개수 규약: num_points = 최종 누적 총량

`previous_stages=[120]`, `num_points=500` → 방출 380, 누적 500.
"500개 낙하 점을 생성한 다음 120개와 가까운 것을 제거" 라는 원 요청과 일치한다.
`num_points` 를 '이번에 추가할 개수'로 해석하지 않는다(사용자 확정).

## 거리 척도는 물리 낙하방향

`sampling_space` 가 `latlon` 이어도 거리는 `_physical_drop_dir` 로 계산한다.
"가깝다" 는 실제 충격 방향이 비슷하다는 뜻이지, 오일러 파라미터가 비슷하다는 뜻이 아니다.
lat/lon 공간의 거리는 극 근처에서 심하게 왜곡된다.

## 제거 알고리즘: prev별 최근접 (전역 그리디 아님)

두 방식의 품질이 **동일**했다(누적 500 기준 둘 다 최소간격 4.59° / 중앙 7.66°).
전역 그리디는 모든 (prev, cand) 쌍을 만들어 O(P·N) 메모리를 쓰므로 큰 N 에서 터진다.
품질이 같으니 O(N) 메모리인 prev별 최근접을 택했다.

## 품질 손실은 받아들인 것

누적 1000 의 최악 간격이 정규 1000 대비 3.15° vs 5.60° (약 56%) 로 낮아진다.
서로 다른 격자를 겹치는 이상 불가피하다. 중앙값(4.73° vs 6.10°)은 거의 유지되고
심한 뭉침·중복은 0 이므로 실용상 수용. **정규 수준 균일도가 필요하면 단계를 쓰지 말 것.**

## 🔴 알려진 함정 — 단계 목록 누락

실제로 `120 → 500` 을 돌려놓고 `previous_stages=[500]` 이라고만 적으면, 재현이
`gen(500)` 단독이 되어 실제 돌린 위치와 어긋난다. 실측: 1000개 중 **4개가 1° 이내 중복**.
치명적이진 않지만 조용히 낭비된다.

자동 검출은 불가능하다(과거에 무엇을 돌렸는지 코드가 알 수 없음). 대신
`_staged_lattice` 가 재현 누적 개수를 로그로 찍는다.

```
단계별 각도 생성: 이전 단계 [120] → 재현 누적 120개, 이번 신규 380개, 최종 누적 500개
```

이 줄의 "재현 누적" 이 실제로 돌린 개수와 같은지 확인하는 것이 유일한 방어선이다.

## 단계 간 설정 고정 의무

`progressive` / `principal_directions` / `sampling_space` 가 단계마다 다르면 재현이
깨진다. 재현은 `num_points` 만 바꾼 같은 설정으로 수행하므로, 실제로 돌릴 때도 같은
설정을 유지해야 한다. 코드로 막을 방법이 없어 문서 경고로 둔다.
