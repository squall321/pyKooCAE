# KMM v126 묶음 계획 (2026-10-27)

## 왜

- 사용자 지시는 "계속진행해 운영까지 ㄱㄱ" 이다. 빌드 → SIF → tar → Drive·메일 → 헤드 /opt 까지 간다.

## 무엇을
1. **내보내기에서 요소가 빠지면 🔴 + 비 0 종료** (사용자 결정 "요소 소실 시 비 0 종료 (Recommended)").
   - 지금은 솔리드 출력기가 요소 하나를 못 쓰면 경고만 내고 건너뛴 뒤 rc 0 으로 끝난다.
   - 재현: KooRemapper merge 예제(`examples/merge/three_layer.k`)는 *NODE NID 를 10칸에 쓴다. 절점 36개가 NID 0 하나로 뭉치고, 요소 12개가 모두 빠지는데 rc 0 이다.
   - 바꿀 것: 건너뛴 요소를 모듈에서 센다. KMM 이 끝날 때 하나라도 있으면 🔴 요약(개수·EID 몇 개·흔한 원인)을 찍고 종료 코드 3 으로 끝낸다. 출력 .k 는 진단용으로 남긴다.
   - 셸·빔·질량 출력기는 지금도 같은 상황에서 예외(rc 1)로 죽는다. 그 동작은 그대로 둔다.
2. **part_yield MAT_017 = min(SIGY, FS)** (사용자 결정 "min(SIGY, FS) (Recommended)").
   - 유리처럼 FS(파괴응력)가 SIGY 보다 작은 재질은 FS 에서 먼저 깨진다. 지금은 SIGY 로 안전율을 내 과대평가한다.
   - 양수인 값 중 작은 것을 쓴다. FS 가 더 작으면 출처를 "MAT_ORIENTED_CRACK FS(파괴)" 로 적는다.
3. **KMM 옵션 파일 `*Recipe,<이름>[,<판>]`** (레시피 2단계).
   - MCP 레시피 등록소(/data/SmartTwinMCP/recipes)에 저장된 kmm_chain·kmm_<모드> 레시피를 옵션 파일에서 이름으로 부른다. 매개변수는 다음 줄들에 `이름,값` 으로 준다.
   - KMM 이 레시피를 읽어 `*Mode` 목록과 모드 블록으로 펼친다. 펼친 옵션 글은 `<옵션>_recipe.txt` 로 남기고 그것을 읽는다.
   - 펼치는 규칙은 MCP 와 같다. 매개변수 타입·범위·enum 검사, `{{이름}}` 채우기, 값 표기(실수 repr·참거짓 True/False), 블록 이름(KMM help 카탈로그)이 같다. 판 해시(sha256)가 맞지 않으면 거절한다.
   - `*Recipe` 가 없는 옵션 파일은 지금과 바이트까지 같게 읽는다.
4. **KAM `eval` 교체** — PackageGenerator 의 DEFINE_CURVE_FUNCTION 식을 AST 화이트리스트로 계산한다.
   - 지금은 옵션 파일의 식 글을 `eval` 해 임의 코드가 돈다.
   - 수·사칙·거듭제곱·나머지·괄호·math 함수(np.·math. 접두 포함)·pi·e·tau 만 허용한다. 큰 정수 거듭제곱은 실수로 계산해 멈추지 않게 한다.
   - 허용하는 식의 값은 예전 eval 과 같다(출력은 `>20.13e` 라 int·float 차이도 없다).

## 성공 기준
- 아는 불량부터: 새 시험이 지금 코드(b480941)에서 실패하는지 먼저 본다.
  - merge 덱이 rc 0 → 새 시험 실패.
  - MAT_017 FS < SIGY 가 SIGY → 실패.
  - `*Recipe` 를 모른다 → 실패.
  - KAM 식 `__import__('os')…` 가 돈다 → 실패.
- 그다음 고친 코드에서 통과해야 한다. 그리고 기존 시험 35종이 전부 통과해야 한다.
- 말뭉치 P(지난 말뭉치 + 이번 시험 덱): 예전 사례는 산출물 md5 가 전부 같아야 한다. 다른 것은 의도한 것(요소 소실 덱 rc 3 등)만이어야 한다.
- 적대 리뷰에서 확정 결함 0(또는 고친 뒤 다시 확인).
- 컴파일본 e2e: 위 네 가지를 실행 파일로 의미 판정한다(`*Recipe` 는 PyYAML·한글 로그가 컴파일본에서 도는지). 지난 판 e2e 묶음도 다시 돌린다.
- 운영: SIF v126 → compute-node-images·tar·Drive·메일 → 헤드 /opt 교체 후 다시 확인한다. 노드 배포는 VM 이 켜질 때 한다(deploy_apptainers.sh).
