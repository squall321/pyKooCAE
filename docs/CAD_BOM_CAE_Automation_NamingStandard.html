CAD 표준화가 시뮬레이션 자동화의 열쇠인 이유

기구 CAD에 BOM이 정해져 있으면, 파트 이름에서 재질 · 요소 타입 · 접촉 조건 · 공정 조건을 자동으로 유추할 수 있습니다. 이 정보만 있으면 SmartTwinCluster에서 전각도 낙하부터 특정 부품만 추출한 공정 시뮬레이션까지 모든 것이 자동화됩니다.

현재의 병목

  • CAD 파트 이름이 설계자마다 다름
  • BOM → FE 모델 매핑에 수작업 필요
  • 시뮬레이션마다 모델을 처음부터 구성
  • 공정 시뮬레이션은 별도 모델을 수동 생성
  • 낙하 각도별로 26개+ 케이스 수동 설정

표준화 후 자동화

  • BOM 변경 → 시뮬레이션 자동 재구성
  • 이름에서 재질·메쉬·접촉 자동 추론
  • 하나의 풀 모델에서 서브셋 자동 추출
  • 디스플레이 압착, 배터리 압착 등 자동 구성
  • 전각도 낙하 26개 케이스 원클릭 생성
핵심 원칙: 파트 이름 = 메타데이터. 이름만 보고도 MAT 카드, 요소 타입, 접촉 조건, 서브셋 추출 범위를 결정할 수 있어야 한다.

필드역할자동화 활용규칙예시
Assembly 제품 / 최상위 어셈블리 시뮬레이션 프로젝트 분류 대문자, 약어 가능 PHONE, TABLET, MODULE
SubAssy BOM 중간 레벨 서브어셈블리 서브셋 추출 단위, 접촉 규칙 기준 기능 그룹 단위 HOUSING, BATTERY, DISPLAY
PartType 파트의 기능/형상 역할 요소 타입 · 메쉬 전략 결정 사전 정의 어휘 COVER, FRAME, POUCH, CELL
Material 재질 코드 MAT 카드 자동 매핑 하이픈으로 등급 구분 PC-ABS, AL6061, SUS304
Instance 동일 파트 복수 배치 Part ID 자동 부여 3자리 숫자 (001~) 001, 002, 003

SubAssy가 핵심인 이유

SubAssy 필드는 단순 분류가 아닙니다. 이 필드가 다음을 자동으로 결정합니다:
• 접촉 규칙 — 같은 SubAssy 내부 = TIED (접합), 다른 SubAssy 간 = CONTACT (접촉)
• 서브셋 범위 — *_DISPLAY_*로 디스플레이 관련 파트만 추출
• 공정 시뮬레이션 대상 — SubAssy 단위로 공정 조건 자동 매핑

제품 메타데이터 구조 (Product Metadata JSON)

BOM + CAE 속성 + 시뮬레이션 시나리오를 하나의 JSON으로 통합. 이 파일이 SmartTwinCluster의 전체 자동화 입력이 됩니다.

3.1 파트 정의 — BOM / CAE / Automation 3계층

{
  "product": "PHONE_X1",
  "bom_version": "R03",
  "material_library": "material_library.json",

  "parts": [
    {
      "part_name": "PHONE_HOUSING_COVER_PC-ABS_001",

      // BOM 원본 정보 (CAD/PDM에서 추출)
      "bom": {
        "part_number": "PN-10234",
        "material_spec": "PC/ABS T65XF",
        "thickness_mm": 0.8,
        "mass_g": 12.3,
        "supplier": "ABC Corp"
      },

      // 시뮬레이션 속성 (이름에서 자동 추론 + 오버라이드)
      "cae": {
        "element_type": "shell",
        "material_model": "MAT_024",
        "material_card": "PC-ABS_T65XF.k",
        "mesh_size_mm": 1.0,
        "contact_role": "exterior"
      },

      // 자동화 파이프라인 제어
      "automation": {
        "mesh_source": "cad_auto",
        "requires_midsurf": true,
        "can_rigidify": false,
        "process_target": false,
        "subset_groups": ["housing", "full_drop"]
      }
    }
  ]
}

3.2 접촉 규칙 — 이름 기반 자동 정의

"contact_rules": [
  {
    "name": "subassy_internal_bond",
    "rule": "SAME_SUBASSY",
    "type": "TIED_SURFACE_TO_SURFACE",
    "tolerance_mm": 0.5,
    // 같은 SubAssy 내 인접 → 자동 TIED
  },
  {
    "name": "inter_assy_contact",
    "rule": "DIFF_SUBASSY",
    "type": "AUTOMATIC_SURFACE_TO_SURFACE",
    "friction": 0.3,
    // 다른 SubAssy 간 → 접촉
  },
  {
    "name": "exterior_self",
    "scope": "contact_role:exterior",
    "type": "AUTOMATIC_SINGLE_SURFACE",
    "soft": 2, "depth": 3
  }
]

전각도 낙하 시뮬레이션 (26 Angles)

6면 + 12모서리 + 8꼭짓점 = 26개 방향의 낙하 시뮬레이션을 자동 생성합니다.

방향 유형개수각도 자동 계산
면 낙하 (Face)6Front, Back, Left, Right, Top, Bottom
모서리 낙하 (Edge)12각 모서리의 중심선 방향으로 45° 조합
꼭짓점 낙하 (Corner)8대각선 방향 (45°, 45°) 조합
자동화 포인트: 이름 표준에서 can_rigidify 속성으로 PCB, 카메라 등을 강체로 자동 전환. contact_role: exterior인 파트만 자동으로 SINGLE_SURFACE 접촉 적용.

  "model": "FULL",

  "surface": "steel_plate",

    { "id": "F02", "name": "face_back",   "pitch": 180, "yaw": 0 },
    { "id": "E01", "name": "edge_top_fr", "pitch": 45,  "yaw": 0 },
    { "id": "C01", "name": "corner_TFL", "pitch": 45,  "yaw": 45 },
    // ... 26개 자동 생성
  ],
  "rigidified": ["PHONE_PCB_*", "PHONE_CAMERA_*"],
  "cluster": { "nodes": 4, "cores_per_job": 16 }
}

디스플레이 압착 (Display Bonding) 시뮬레이션

OLED 패널을 프레임에 OCA 접착제로 압착하는 공정. DISPLAY SubAssy + HOUSING_FRAME만 추출하여 해석합니다.

추출되는 파트:
DISPLAY_GLASS_GORILLA DISPLAY_PANEL_OLED DISPLAY_ADHESIVE_OCA HOUSING_FRAME_AL6061
자동 설정:
  • 프레임 하면 고정 (fixed BC)
  • 유리 상면에 균일 압력 0.5 MPa
  • OCA 접착층에 MAT_083 (점탄성)
  • 온도 조건 60°C (열 연화 반영)
{
  "simulation": "PHONE_X1_DISPLAY_BONDING",
  "type": "process",
  "subset_filter": ["*_DISPLAY_*", "*_HOUSING_FRAME_*"],
  "boundary": {
    "fixed": "*_HOUSING_FRAME_*:bottom_face",
    "pressure": { "target": "*_DISPLAY_GLASS_*:top_face", "value_MPa": 0.5 }
  },
  "thermal": { "uniform_C": 60 },
  "output": ["stress_OCA", "gap_distribution", "bonding_area_ratio"]
}

배터리 압착 (Battery Press-Fit) 시뮬레이션

배터리를 하우징 프레임 안에 끼워넣는 공정. BATTERY SubAssy + HOUSING_FRAME을 추출하여 간섭 끼워맞춤 해석.

추출되는 파트:
BATTERY_POUCH_AL1100 BATTERY_CELL_JELLYROLL BATTERY_PAD_FOAM HOUSING_FRAME_AL6061
자동 설정:
  • 프레임 외면 고정
  • 배터리에 press 변위 하중
  • 폼 패드에 MAT_057 (저밀도 폼)
  • 간섭량 -0.05mm 자동 적용
{
  "simulation": "PHONE_X1_BATTERY_PRESS",
  "type": "process",
  "subset_filter": ["*_BATTERY_*", "*_HOUSING_FRAME_*"],
  "boundary": {
    "fixed": "*_HOUSING_FRAME_*:outer_face",
    "displacement": { "target": "*_BATTERY_*:top", "dz_mm": -2.0 }
  },
  "interference": { "clearance_mm": -0.05 },
  "output": ["cell_deformation", "frame_stress", "insertion_force"]
}

열 해석 (Thermal Analysis)

충전 중 배터리 발열이 디스플레이와 PCB에 미치는 영향 해석. 전체 모델 또는 관심 영역 서브셋 선택 가능.

열원 파트 (자동 감지):
BATTERY_CELL_JELLYROLL PCB_MAIN_FR4
자동 설정:
  • 배터리 셀 → 열원 (발열량 자동)
  • PCB → 칩 위치별 국부 열원
  • 외면 → 자연대류 경계조건
  • 재질별 열전도도 자동 매핑
{
  "simulation": "PHONE_X1_THERMAL",
  "type": "thermal",
  "subset_filter": "ALL",
  "heat_sources": [
    { "target": "*_BATTERY_CELL_*", "power_W": 3.5 },
    { "target": "*_PCB_MAIN_*",    "power_W": 2.0 }
  ],
  "convection": { "scope": "contact_role:exterior", "h_W_m2K": 10, "T_amb_C": 25 }
}

3점 굽힘 시험 (Three-Point Bending)

완제품의 구조 강성 평가. 전체 모델을 사용하되, 일부 내부 부품은 강체로 단순화.

전체 모델 사용, 강체화:
ALL PARTS (Full Model)
PCB_* → Rigid CAMERA_* → Rigid
자동 설정:
  • 하부 2점 지지 (양 끝단)
  • 상부 1점 하중 (중앙)
  • can_rigidify: true 파트 자동 강체화
  • 출력: 하중-변위 곡선, 최대 응력
{
  "simulation": "PHONE_X1_3POINT_BEND",
  "type": "structural",
  "subset_filter": "ALL",
  "rigidify_auto": true,
  "boundary": {
    "support_span_mm": 120,
    "load_point": "center",
    "force_N": 50
  },
  "output": ["force_displacement", "max_stress_by_part", "stiffness_N_mm"]
}

SmartTwinCluster 연동 포인트

1. 시나리오 자동 생성

Product Metadata의 simulations 배열에서 각 시뮬레이션의 입력 파일을 자동 생성합니다.

  • 풀 모델 → 낙하/굽힘/열해석 입력
  • 서브셋 모델 → 공정 시뮬레이션 입력
  • 재질 카드 → material_library에서 자동 수집
  • 접촉 정의 → contact_rules에서 자동 생성

2. 클러스터 병렬 실행
