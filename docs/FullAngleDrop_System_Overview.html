전각도 낙하 시뮬레이션 · 한눈 개요

제품을 모든 방향으로 떨어뜨려 가장 위험한 자세를 찾는다. 방향을 고르고 → 모델을 만들고 → 결과를 종합하는 세 단계가 전부다.

설계·제출
prepare · submit
방향 격자를 만들어 모든 방향을 Slurm 잡으로 던진다.
방향마다
run
MeshModifier로 .k 생성 → LS-DYNA 해석.
개별 → 종합
deep → sphere/impact
잡마다 해석하고, 전 방향을 모아 최악 방향을 찾는다.
선택
reprioritize
위험영역 근처 대기 잡을 먼저 돌게 재배치한다.

◎① 방향 고르기

구 위에 낙하 방향을 점으로 뿌린다. 점 하나 = 자세 하나 = 해석 하나.

🌐 전수 1천각

1000개 방향을 전부 해석. 완전하지만 시간·비용이 최대다.

⚙② 모델 만들기

KooMeshModifier가 방향 하나당 해석용 .k 하나를 만든다. 모델을 돌리고 바닥과 조건을 붙인다.

  • 1
    제품을 목표 자세로 회전 — roll·pitch·yaw
  • 2
    낙하 바닥면 생성 — 평면 / 등급메시 / 강체벽
  • 3
    접촉 정의 — 자기접촉(SINGLE_SURFACE), 접착면 제외
  • 4
    해석 제어·초기속도 — 타임스텝 안정화, 낙하높이 v=√(2gh)
  • 5
    경계·출력 설정 — 바닥 고정/응력파 흡수, d3plot·접촉력

▦③ 결과 종합하기

핵심은 단 하나 — deep는 1건, sphere는 방향 종합, impact는 위치 종합.

deep개별
해석 1건을 읽는다

d3plot에서 파트별 최대응력·변형·안전계수를 뽑아 result.json으로. 끝나면 d3plot은 지운다.

sphere방향
전 방향을 구에 칠한다

모든 낙하 방향의 deep 결과를 구면 히트맵으로 → 어느 방향이 가장 위험한지 한눈에.

impact위치
전 위치를 면에 칠한다

충격자가 때린 면 위 여러 위치의 결과를 분포로 → 어느 위치가 가장 위험한지.

같은 고정 격자를 두고, 전수해석과 적응 샘플링은 실행 순서만 다르다 — 위험한 방향을 먼저 찾을 뿐이다.
