DROP_ATTITUDE 옵션 종합 레퍼런스

pyKooCAE 전각도 낙하(DROP_ATTITUDE) 모드 — 낙하면·낙하조건·접촉·기타 옵션 전체. 모든 항목은 실제 코드(파서·핸들러)에서 추출했습니다.

코드 출처 (file:line)
  • Runner/StepConfigBuilder.py:9-175 — scenario simulation_params → step_config 직렬화 (시나리오 키 정본)
  • occProject/Generators/KooMeshModifier.py:1354-1587 — **DropAttitude 블록 파서 (허용 키 전체)
  • occProject/Generators/KooCAEManager/KooDynaAdvancedModification.py:2036-2660 — DropAttitude() 핸들러 (동작·기본값·OptCard·RigidWall)

0. 옵션 입력 흐름

scenario.json
simulation_params→ StepConfigBuilder
(step_config.txt)→ KooMeshModifier
**DropAttitude 파서→ DropAttitude()
핸들러 (.k 생성)

사용자는 simulation_params(+ 하위 drop_surface, drop_contact, tied_options)에만 값을 넣습니다. 표의 시나리오 키가 입력 위치이고, 기본값은 미입력 시 적용되는 값입니다.

1. 낙하 자세 · 낙하 조건

각도는 DOE(각도 소스)에서 자동 생성되며, 아래 값들은 simulation_params 공통값입니다.

시나리오 키config 키기본값설명
(각도 소스)EulerRolling / EulerPitching / EulerYawingDOE 생성낙하 자세(roll/pitch/yaw, deg). angle_source(fibonacci/cuboid 등)로 자동.
heightHeight1500 (mm)낙하 높이. 충돌체를 바닥 위 이 높이에 배치하고 자유낙하 속도 부여.
offset_distanceOffsetDistance0.05충돌체와 바닥면 사이 초기 간격(mm). 초기 관통 방지.
(고정 0)InitialVelocityX/Y/Z0초기 병진속도. StepConfigBuilder는 0 고정(파서는 리스트 입력 지원).
(고정 0)InitialAngularVelocityX/Y/Z0초기 각속도. 동일하게 0 고정.
참고 — InitialVelocity*/InitialAngularVelocity*는 파서(KooMeshModifier.py:1402-1443)는 다값 리스트를 받지만, StepConfigBuilder는 항상 0으로 직렬화합니다(StepConfigBuilder.py:159-164). 초기속도를 주려면 step_config를 직접 편집하거나 빌더 확장이 필요합니다.

2. 충돌체 재료 · 해석 시간

단위계 [tonne, mm, s, MPa]. 강철 기준 ρ=7.85e-9, E=2.0e5.

시나리오 키config 키기본값설명
densityDensity7.85e-9 (tonne/mm³)바닥판(생성형 Plane) 재료 밀도. RigidWall이면 불필요.
youngs_modulusYoungsModulus2.0e5 (MPa)바닥판 영률.
poisson_ratioPoissonRatio0.3바닥판 포아송비.
tFinaltFinal0.005 (s)해석 종료 시간.
dtdt1e-6 (s)출력(D3PLOT) 시간 간격.

3. 낙하면 (DropSurface) 4종

낙하면은 simulation_params.drop_surface.type으로 선택합니다 — Plane / PlaneGraded / PlanewithRoughness / RigidWall. (파서 KooMeshModifier.py:1471-1513)

3-1. Plane (기본) — 균일 메시 평판

키 (drop_surface.*)기본값설명
type"Plane"균일 메시 직육면체 바닥판.
size[300, 300, 20][X, Y, 두께] (mm).
mesh[30, 30, 2][nx, ny, nz] 요소 분할 수.

3-2. PlaneGraded — 중심 균일 + 외곽 graded

키 (drop_surface.*)기본값설명
type"PlaneGraded"중심부 균일 메시 + 외곽으로 갈수록 커지는 graded 메시.
size[200, 200, 20]중심 균일부 [X, Y, 두께].
mesh[10, 10, 2]중심부 [nx, ny, nz].
num_outer_layers5외곽 graded 레이어 수.
ratio1.5외곽 레이어 크기 증가율.

3-3. PlanewithRoughness — 거칠기 부여 평판

키 (drop_surface.*)기본값설명
type"PlanewithRoughness"표면 거칠기(요철)를 부여한 평판.
size / mesh[300,300,20] / [30,30,2]Plane과 동일.
roughness_mode"Random"거칠기 패턴 — Random / XRandom / YRandom / XSin / YSin / XYSin (파서 주석 :1506).
r_max0.0최대 요철 높이(mm).
shape_factor0.0형상 계수 1.
shape_factor2shape_factor형상 계수 2 (생략 시 shape_factor와 동일).

3-4. RigidWall — 무한 강체 평면 (메시 없음)

메시 바닥판 대신 *RIGIDWALL_PLANAR_MOVING_FORCES 사용. 바닥판 파트·접촉을 만들지 않습니다(:2638-2661). 세부 옵션은 8장 참조.

키기본값설명
type"RigidWall"config는 DropSurface,RigidWall,0,0,0,0,0,0로 직렬화.

4. DeformableToRigid

시나리오 키config 키기본값설명
drop_surface.deformable_to_rigidDeformableToRigidfalsetrue면 변형체 바닥판을 강체로 전환(*DEFORMABLE_TO_RIGID). 계산 비용↓.

5. 접촉 변환 옵션 (SINGLE_SURFACE 자가접촉)

모델 자가접촉(전체 파트 SINGLE_SURFACE) 생성을 제어합니다. 중요 이 옵션들이 빠지면 자가접촉 part set이 안 생길 수 있습니다(핸들러 :2272-2274).

시나리오 키config 키기본값설명
convert_general_to_single_surfaceConvertGeneralToSingleSurfacetrue모델의 AUTOMATIC_GENERAL 접촉을 SINGLE_SURFACE(SOFT=2)로 변환(part set 생성).
ensure_single_surfaceEnsureSingleSurfacefalseGENERAL도 SINGLE_SURFACE도 없을 때 전체 파트로 SINGLE_SURFACE 강제 생성. GENERAL 접촉이 없는 모델은 이 값을 true로 줘야 자가접촉이 생김.
decompose_general_contactDecomposeGeneralContactfalseGENERAL 접촉을 개별 S2S 페어로 분해.
decompose_contact_marginDecomposeContactMargin1.5분해 시 상대 마진.
decompose_contact_absolute_margin_x/y/zDecomposeContactAbsoluteMarginX/Y/Z5.0 / 5.0 / 0.5분해 시 절대 마진(mm).
include_wall_in_generalIncludeWallInGeneralfalse바닥판을 GENERAL 접촉에 포함.
자가접촉 part set이 생성되는 조건 — (a) 모델에 GENERAL 접촉이 있어 convert_general_to_single_surface(기본 on)가 변환하거나, (b) ensure_single_surface: true로 강제. 둘 다 아니면 자가접촉이 안 만들어집니다.

11. 제어 카드

아래 카드는 핸들러가 모델에 해당 카드가 없을 때만 자동 생성합니다. 모델에 이미 있으면 그 값이 보존됩니다. 제어 가능 항목은 simulation_params.control_timestep / control_hourglass dict로 override합니다(handler :1886-1900).

카드 / 값제어시나리오 키 / 기본값
*CONTROL_TIMESTEP TSSFAC가능control_timestep.TSSFAC · 기본 0.7
*CONTROL_TIMESTEP DT2MS가능control_timestep.DT2MS · 기본 0.0 (질량 스케일링)
*CONTROL_TIMESTEP DTINIT/ISDO/TSLIMT/LCTM/ERODE/MS1ST가능control_timestep.{KEY} · ERODE 기본 1, 그 외 0
*CONTROL_HOURGLASS IHQ / QH가능control_hourglass.IHQ(기본 5) / control_hourglass.QH(기본 0.1)
SOFSCL (접촉)가능drop_contact.SOFSCL · 기본 0.1 (7장)
"simulation_params": {
  "control_timestep": { "TSSFAC": 0.9, "DT2MS": -1e-07 },
  "control_hourglass": { "IHQ": 6, "QH": 0.05 }
}
override는 모델에 해당 CONTROL 카드가 없을 때만 적용됩니다(있으면 모델 값 보존). 공유 헬퍼 SetControlandDatabaseExplicit에 배선되어 DROP뿐 아니라 동일 키로 확장 가능합니다.
