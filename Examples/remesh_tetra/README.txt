================================================================================
REMESH_TETRA — 사면체 파트 리메시
================================================================================

목적:
  찌그러진 사면체 요소를 gmsh로 리메시하여 메시 품질 개선.
  최소 dt를 보장하여 해석 안정성 확보.

================================================================================
사용법
================================================================================

  KooMeshModifier step_config.txt

================================================================================
step_config 형식
================================================================================

  *Inputfile
  model.k
  *Mode
  REMESH_TETRA,1
  **RemeshTetra,1
  *PID,100099,35202
  *MinDt,1.0e-8
  *TargetEdgeLength,0.5
  *MaxAspectRatio,10.0
  *SmoothingIterations,5
  *PreserveSharedNodes,True
  **EndRemeshTetra
  *End

================================================================================
옵션 설명
================================================================================

  *PID,{pid1},{pid2},...
    리메시 대상 파트 ID 리스트. 사면체(TETRA4)만 지원.

  *MinDt,{value}
    최소 보장 timestep (초). 이 값을 만족하는 최소 요소 크기를
    gmsh CharacteristicLengthMin으로 설정.
    기본: 0 (제한 없음)

  *TargetEdgeLength,{value}
    목표 요소 크기 (mm). gmsh CharacteristicLengthMax로 설정.
    기본: 0 (기존 평균 요소 크기 유지)

  *MaxAspectRatio,{value}
    검증 시 허용 최대 aspect ratio (max_edge / min_edge).
    초과 요소가 있으면 경고 출력.
    기본: 10.0

  *SmoothingIterations,{value}
    gmsh 후처리 Laplacian smoothing 반복 횟수.
    기본: 5

  *PreserveSharedNodes,{True|False}
    다른 파트와 공유하는 노드의 좌표/ID를 보존할지 여부.
    True: 공유 노드 고정 → Tied/접촉 안전 (기본)
    False: 공유 노드도 리메시 → 외곽면 품질 최대 개선,
           Tied/접촉 재매핑 필요

================================================================================
동작 흐름
================================================================================

  1. 대상 파트 사전 분석
     - 요소 수, edge 길이 분포, min dt 출력
     - 재료 물성 → 음속 → L_min 계산

  2. 공유 노드 수집
     - 다른 파트와 겹치는 노드 식별
     - PreserveSharedNodes=True면 gmsh 고정점으로 지정

  3. 외곽면 STL 추출 → gmsh 3D 리메시
     - feature edge 자동 감지 (40도)
     - HXT 알고리즘 + Netgen 최적화
     - AnisoMax=3.0 → 납작한 요소 방지
     - QualityType=SICN → 품질 메트릭 기반 최적화

  4. 결과 교체
     - 기존 노드/요소 제거 → 새 것으로 교체
     - 공유 노드는 원본 ID 유지
     - 재료/섹션/PID 불변

  5. 검증
     - 새 요소 dt, edge 길이, aspect ratio 출력
     - min_dt 미달 또는 bad aspect ratio 있으면 경고

================================================================================
scenario.json (KooChainRun 연동)
================================================================================

  {
    "simulation_params": {
      "remesh_tetra": {
        "pids": [100099, 35202],
        "min_dt": 1.0e-8,
        "target_edge_length": 0.5,
        "max_aspect_ratio": 10.0,
        "smoothing_iterations": 5,
        "preserve_shared_nodes": true
      }
    }
  }

================================================================================
주의사항
================================================================================

  - 사면체(TETRA4)만 대상. HEXA8, PENTA6 등은 skip.
  - gmsh가 설치되어 있어야 함 (Library/gmsh-4.14.1-Linux64/bin/gmsh)
  - 리메시 후 초기 응력/변형률은 소실됨
  - 실행 순서: REMESH_TETRA → DROP_ATTITUDE → robust_contact
  - PreserveSharedNodes=False일 때 Tied 접촉 재확인 필요
