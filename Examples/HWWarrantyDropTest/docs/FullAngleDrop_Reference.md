# Full Angle Drop - Reference Guide

## Overview

전각도(Full Angle) 낙하 시뮬레이션에서 등간격으로 모든 방향을 커버하기 위한 참조 가이드입니다.

---

## 1. 구면 등간격 배치 방법

### 1.1 기하학적 배치 (Geometric)

| 방법 | 케이스 수 | 각도 간격 | 설명 |
|------|----------|----------|------|
| 정팔면체 (Octahedron) | 6 | 90° | 6면 낙하 (F1~F6) |
| 정이십면체 꼭짓점 (Icosahedron Vertices) | 12 | 63° | 12개 꼭짓점 |
| 정이십면체 면중심 (Icosahedron Face Centers) | 20 | 45° | 20개 면 중심 |
| **직육면체 기하 (Cuboid Geometry)** | **26** | **40°** | **6면 + 12모서리 + 8꼭짓점** |
| 정이십면체 복합 | 32 | 36° | 12 꼭짓점 + 20 면중심 |

### 1.2 피보나치 격자 (Fibonacci Lattice)

구면에서 점을 가장 균등하게 분포시키는 알고리즘입니다.

**평균 각도 간격 공식**: θ ≈ √(4π/N) × (180/π) 도

## 3. 26개 직육면체 기하 배치 상세

스마트폰과 같은 직육면체 형상에 최적화된 배치입니다.

### 3.1 구성

```
총 26개 = 6개(Face) + 12개(Edge) + 8개(Corner)

┌─────────────────────────────────────────────────────────┐
│  Face (6개)     : F1~F6  (각 면의 중심 방향)              │
│  Edge (12개)    : E1~E12 (각 모서리 방향, 45° 기울기)     │
│  Corner (8개)   : C1~C8  (각 꼭짓점 방향, 대각선)         │
└─────────────────────────────────────────────────────────┘
```

## 4. 피보나치 격자 알고리즘

```python
import math

def fibonacci_sphere(n):
    """N개의 점을 구면에 균등 분포 (피보나치 격자)"""
    points = []
    phi = math.pi * (3.0 - math.sqrt(5.0))  # 황금각

    for i in range(n):
        y = 1 - (i / float(n - 1)) * 2  # y: 1 to -1
        radius = math.sqrt(1 - y * y)
        theta = phi * i

        x = math.cos(theta) * radius
        z = math.sin(theta) * radius

        # 방향 벡터 (x, y, z) -> 오일러 각도 변환 필요
        points.append((x, y, z))

    return points
```

## 6. 참고 사항

1. **26개 배치**는 피보나치 격자가 아닌 **직육면체 기하학적 배치**입니다.
2. **피보나치 격자**는 임의의 N에 대해 가장 균등한 구면 분포를 제공합니다.
3. 스마트폰 같은 직육면체 제품은 26개 기하학적 배치가 물리적으로 의미있습니다.
4. 순수 균등 분포가 필요하면 피보나치 격자를 사용하세요.
