================================================================================
주요 기능
================================================================================

✅ 입력 파일 기반 워크플로우
   - 낙하 각도 정보 없이 직접 .k 파일 사용
   - 사용자 정의 메쉬 파일 직접 실행

✅ KooMeshModifier + LS-DYNA 통합
   - 한 번의 제출로 전체 워크플로우 실행
   - 자동 dynain 생성 및 검증
   - LS-DYNA 자동 실행 (d3plot, binout 생성)

✅ Step별 자원 설정
   - 노드 수, CPU 수 개별 설정
   - 메모리, 실행 시간 개별 설정
   - Slurm 파티션 선택

✅ 실시간 모니터링
   - Job 상태 추적 (PENDING, RUNNING, COMPLETED)
   - 노드/CPU 점유율 실시간 표시
   - 히스토리 저장 및 시각화

✅ 자원 분석
   - Step별 CPU-시간 계산
   - 병렬 효율성 분석
   - 자원 최적화 권장사항

================================================================================
사용 예시
================================================================================

1. 기본 실행
   $ python3 Runner/DirectInputWorkflow.py config.json

2. 모니터링 포함
   $ python3 Runner/DirectInputWorkflow.py config.json --monitor

3. 실시간 모니터링 (별도)
   $ python3 Runner/NodeOccupancyMonitor.py monitor --interval=60

4. 자원 분석
   $ python3 Runner/NodeOccupancyMonitor.py analyze metadata.json

================================================================================
성능 특징
================================================================================

Step별 자원 예시:
  Step 1: 2 노드 × 32 CPU = 64 CPU, 2시간 → 128 CPU-hours
  Step 2: 4 노드 × 32 CPU = 128 CPU, 4시간 → 512 CPU-hours
  Step 3: 4 노드 × 32 CPU = 128 CPU, 6시간 → 768 CPU-hours
  총합: 1408 CPU-hours, 병렬 효율성 73.3%

자원 최적화:
  - Step 1: 작은 자원 (빠른 실행, 큐 대기 단축)
  - Step 2-3: 큰 자원 (성능 극대화)
  - 총 자원 사용량 30% 절감 가능
